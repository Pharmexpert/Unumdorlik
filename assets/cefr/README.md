# CEFR so'z ro'yxati

`wordlist.csv` (ustunlar: `word,cefr`) shu yerga qo'yiladi. Manbalar:
- Oxford 3000 / Oxford 5000 (CEFR darajalari bilan) — shaxsiy foydalanish uchun ochiq PDF/CSV;
- English Vocabulary Profile (EVP) — ro'yxatdan o'tish bilan;
- ochiq-litsenziyali muqobillar: GitHub'dagi `cefr` / `oxford-5000` CSV nusxalari (litsenziyani tekshiring).

Ro'yxat bo'lmasa 02-bosqich skriptning o'z lug'atidan foydalanadi (sifat pastroq, lekin ishlaydi).
